# RAM DIGITAL website starter

A responsive, dark premium one-page website inspired by the general visual direction of the reference: black background, warm gold accents, pink/orange gradients, rounded service cards and mobile navigation. This is an original starter, not a copy of another site's code or branding.

## Files
- `index.html` — page structure and editable copy
- `style.css` — visual styling and mobile breakpoints
- `script.js` — mobile menu and current year

## Before publishing
1. In `index.html`, replace `YOUR_EMAIL@example.com` with your business email.
2. Replace `91YOURPHONENUMBER` in the WhatsApp link with your country code and phone number, digits only.
3. Replace the sample portfolio cards with links and work you have permission to showcase.
4. Only publish client names, logos, metrics and results that you are authorized to share.
5. Optional: replace the sample “360° / SEO / Data” metrics with verified figures.

## Free publishing with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a public repository named `ram-digital-website`.
3. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
4. Open **Settings → Pages**.
5. Under build/deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
6. GitHub will show the published website URL after deployment completes.

GitHub Pages can host a static site for free. A custom domain is optional and usually costs money to register. The contact buttons use email/WhatsApp links; this starter does not include a backend inquiry form.
